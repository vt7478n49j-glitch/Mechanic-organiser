Mechanic Mate v43.10

Prepared from the v43.9 HTML and service worker supplied in this chat.
This is a local update package. The GitHub repository and live site have not been changed.

WHAT CHANGED

1. Settings > Cloud sync now includes Forgot password?. Enter your account email
   and press that button to request a reset email. Opening the email link returns
   to a Reset your password screen with new-password and confirmation fields.
   Password recovery uses a separate temporary session and does not trigger data
   synchronisation. After saving the password, sign in with the new password.

2. Dashboard and Jobs use the same card and badge colours:
   Pending: grey
   Booked: blue
   In progress: purple
   Ready to Invoice: amber
   Complete (with an invoice already linked): light green
   Invoiced: teal
   Paid: green
   Cancelled: red
   Status labels remain visible, and colours update with status changes.

3. New quotes use QUO-DDMMYY-NN, for example QUO-290926-01.
   The sequence advances per quote date. Changing the date on a new quote updates
   the suggested number. Existing saved quote and invoice numbers are preserved.
   Duplicate quote numbers and invalid quote dates are rejected on save.

4. The service worker has a new cache version and caches only same-origin GET
   requests, so authenticated Supabase lookups are not stored in its offline cache.
