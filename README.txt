MECHANIC MATE v3

Changes in this version:
- iPhone Dynamic Island / safe-area spacing fixed.
- Settings now includes an hourly labour rate.
- Jobs can record time spent and calculate labour from your hourly rate.
- Parts can be linked directly to a job.
- Parts can store your cost and the amount charged to the customer.
- Invoices now have a Parts box.
- Invoices can select a recent job and saved customer.
- Selecting a job pulls in its customer, time spent and linked parts automatically.
- Existing Mechanic Mate local data uses the same storage key so it should carry over after updating the site.

For GitHub Pages, replace your existing files with these files and commit the changes.
Then open the app once while online so the new service worker can update the cached version.
