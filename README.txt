MECHANIC MATE v4

New in this version:
- + Parts on a job lets you select an existing saved part or add a new one.
- New manually-added parts are automatically saved in the Parts tab.
- Parts can be linked to jobs.
- Jobs store time spent and calculate labour using your hourly rate in Settings.
- Invoices can select a recent job and customer.
- Invoice parts amount is filled from parts linked to the selected job.
- iPhone safe-area support for Dynamic Island/notch.

Update GitHub Pages by uploading/replacing all files in the repository root.
